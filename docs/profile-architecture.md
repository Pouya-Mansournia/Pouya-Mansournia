# Profile architecture

## Positioning

> Robotics engineer and technical founder who builds complete systems, from mechanism and firmware to fleet software and shipped product.

The page should answer five questions in this order: who he is, which domains he works in, what he has built, how deep that work goes, and how to reach him.

## Section order

| # | Section | Job |
|---|---|---|
| 1 | Header banner | Name, role, and domain tags; an AMR route motif sets the robotics identity |
| 2 | Typing line | Four rotating one-line summaries of scope |
| 3 | Links | Website, LinkedIn, email, ROS 2 book, FoundryOS |
| 4 | About | Six bullets: what he builds and how he thinks |
| 5 | Engineering system map | Signature graphic: value chain plus four domains, paired with a clickable link table because SVG links don't work inside GitHub images |
| 6 | Featured projects | Eight curated repositories in a two-column card grid |
| 7 | Technology stack | Grouped by engineering purpose, as text, not badges |
| 8 | Open source & education | The books, EN and FA |
| 9 | GitHub activity | Telemetry stats plus the fleet-floor contribution map (dark and light) |
| 10 | Current focus | Four verifiable threads |
| 11 | Footer | Contact repeated |

## Project taxonomy

- **Robotics & autonomy:** warehouse-amr-ros2, Delivery-Robot-ROS, ros2-zero-to-robot(-fa), RACA, emergent agents
- **Precision & mechatronics:** Piezo-Controller, stepper controllers, FSR, flexures (capability only)
- **AI, embedded & software:** FoundryOS, ARCHON, robot-vision-zero-to-slam, multifunctional-probe
- **Product & founder:** X-ROBOTIICS, Acust.ai sensing (grafana-dashboard, dataset), flexsim-digital-twin

## Founder story

The value chain along the top of the system map (Mechanism → Electronics → Firmware → Software → Product → Deployment) carries the product and ownership message without a business-résumé section.
